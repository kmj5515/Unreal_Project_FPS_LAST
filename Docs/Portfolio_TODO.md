## 🎬 녹화로 "보여줄" 셀링 포인트 (이미 구현됨)

> 위 작업이 끝나면 영상으로 스포트라이트. 이게 포폴의 실질 가치.

1. **WidgetTreeGen 자작 플러그인** ★★★★★ — JSON → UMG 위젯 생성·컴파일·저장 + regen. **엔진 툴링** = 최강 차별화
2. **GAS 모듈 로드아웃** ★★★★ — 데이터 주도 스탯 합성 + Infinite GE (T2 계승자 화면이 가장 잘 보여줌)
3. **태그 기반 화면 라우팅** ★★★★ — 레지스트리 행 1줄 = 새 화면
4. **Subsystem 아키텍처** ★★★ — 책임 분리 + 델리게이트 자동 UI 갱신
